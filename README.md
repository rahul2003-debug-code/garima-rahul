## 🌟 मुख्य विशेषताएं (Key Features)

1. **3D शाही लिफाफा उद्घाटन (Royal 3D Envelope Opening Ceremony)**:
   - पेज खोलते ही एक शाही गोल्ड वैक्स-सील लिफाफा सामने आता है।
   - अतिथि का नाम लिफाफे पर "प्रतिष्ठा में: श्रीयुत् [नाम] सपरिवार" के रूप में सुंदर अक्षरों में दिखता है।
   - सील पर क्लिक करते ही विवाह का मंगल गीत ("हमारी शादी में...") स्वतः बजने लगता है और 3D में लिफाफा खुलकर कार्ड प्रदर्शित होता है।
2. **बैकग्राउंड विवाह संगीत प्लेयर (Floating Royal Music Player)**:
   - शहनाई और विवाह गीत ("हमारी शादी में...") का स्मूथ प्लेयर।
   - इक्वलाइज़र एनिमेशन, ट्रैक बदलने, पॉज़/प्ले और म्यूट करने की पूर्ण सुविधा।
3. **गुलाब की पंखुड़ियों एवं सोने के कणों की वर्षा (Falling Rose Petals & Golden Sparkles Canvas)**:
   - 60fps पर तैरती हुई पंखुड़ियां एवं सुनहरे कण।
   - ऑन/ऑफ बटन की सुविधा।
4. **वर-वधू का राजसी परिचय (Meet the Royal Couple)**:
   - **वधू**: गरिमा वर्मा (ब्रान्च पोस्ट मास्टर) - ग्राम- भलवां, पोस्ट- रूपौधा, जिला- मीरजापुर
   - **वर**: राहुल कुमार (साफ्टवेयर इंजीनियर) - ग्राम व पोस्ट- मसोन, जिला- गाजीपुर
   - दोनों के शाही झरोखा फ्रेम में वास्तविक फोटोग्राफ्स।
5. **शुभ मुहूर्त एवं लाइव काउंटडाउन (Live Countdown to Vivah)**:
   - 11 नवम्बर 2026 के लिए लाइव दिन, घंटे, मिनट, सेकंड की उल्टी गिनती।
   - एक क्लिक में "Google Calendar में जोड़ें" का विकल्प।
6. **मांगलिक कार्यक्रम विवरण**:
   - शुभ-विवाह: 11 नवम्बर 2026, बुधवार (रात्रि लग्नानुसार)
   - भीगी पलकें: 12 नवम्बर 2026, गुरुवार (प्रातः काल)
   - विशेष शायरी: *"भूल न जाना शादी का Date, आना मेरे Gate, गरिमा की शादी है, हम करेंगे आपका Wait......"*
7. **स्थान एवं दिशा-निर्देश (Venue & GPS Navigation)**:
   - ओम् मंगलम् लॉन, रमना (पुलिस चौकी के आगे), वाराणसी
   - गूगल मैप्स पर एक क्लिक में रास्ता देखने और पता कॉपी करने का बटन।
8. **अतिथियों के लिए पर्सनलाइज्ड व्हाट्सएप लिंक जनरेटर**:
   - रिश्तेदार या मित्र का नाम लिखें (जैसे "चाचा जी", "राजेश शर्मा जी") और सीधे व्हाट्सएप पर पर्सनल निमंत्रण संदेश भेजें।
9. **मूल वैवाहिक पत्रिका व्यूअर (Original Scanned Card Modal)**:
   - हाथ से छपे पारंपरिक कार्ड के तीनों पन्नों को हाई-रेज़ोल्यूशन में ज़ूम करके देखने की सुविधा।
10. **शुभकामनाएं एवं उपस्थिति (Wishes Wall & RSVP)**:
    - मेहमान वर-वधू को अपना शुभाशीर्वाद लिख सकते हैं।

## 🚀 GitHub पर कैसे होस्ट करें (Deployment Guide)

### तरीका 1: ऑटोमैटिक (GitHub Actions)
कोड को `main` ब्रांच पर पुश करते ही GitHub Actions स्वतः वेबसाइट को बिल्ड करके GitHub Pages पर लाइव कर देगा:
```bash
git add .
git commit -m "Shubh Vivah Garima & Rahul web card"
git push origin main
```
इसके बाद GitHub रिपॉजिटरी में **Settings -> Pages -> Source** में जाकर **"GitHub Actions"** सेलेक्ट करें।

### तरीका 2: gh-pages कमांड (Manual)
```bash
npm run deploy
```
यह कमांड स्वतः `dist` फोल्डर को `gh-pages` ब्रांच पर अपलोड कर देती है।
